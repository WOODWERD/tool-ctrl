What it is

Tool Ctrl records every tool box you own, the drawers in each one and the tools inside. Every box gets a number that never changes, so a label you print today still matches in five years. Search finds any tool in a few seconds, with the shelf, box and drawer it's in.

It runs in your browser and saves on your device. There's no account. You can also keep the record in a private GitHub repo of your own, which syncs it between your computer, iPad and phone.

Two other tools work from the same record. Box Ctrl prints a label for every box. Stack Ctrl draws your Systainers to scale and lets you stack them. Tool Ctrl holds the facts; they use them.

Getting started

Build the record on a computer or an iPad. A phone is for looking things up.

  1. Give your owner name. Tool Ctrl suggests a prefix from it, such as WW. Every box number starts with it.
  2. Choose how to begin: add a box, start from the tick-list, or import a list you already have.
  3. Open a box and add what's in it: tick tools off the list, type them, or read them from a photo.
  4. Export a backup when you're done, or connect GitHub so it keeps a copy for you.

Box numbers

A box ID is your prefix and a three-digit number: WW-014. Every kind of box, Systainer, Packout, chest or bag, shares one count, and the kind of box is a field, not part of the number.

  • A new box takes the next number after the highest one used.
  • A number is never used twice. Retire a box you no longer have and its ID stays in the record, marked Retired, because a label may still be out there.
  • Where a box sits, what it rides on and what's in it never change its number. Move or repack it and the label stays right.
  • You can add more prefixes, up to four capitals, for a second owner or a set kept apart. Record › Prefixes and kinds of box.

Drawers, trays and carts

Open a box and press Add drawers. Say how many and they are made in one step: a drawer unit with three drawers gets WW-014-D1 to D3. D is a drawer, T a tray and B a fixed bin. Drawers count from the top, starting at 1, and left to right where they sit side by side.

A drawer is the smallest thing with a number. A small case inside a drawer goes in the tool's notes.

Sits on links a box to the one it rides on, such as five Systainers on a cart. Its location then follows the cart. Stack Ctrl sets this for you as you build stacks.

Systainer models

A Systainer, Sortainer, Systainer drawer unit, cart, or a Festool tool that is itself a Systainer, such as a CT SYS, can have its model: SYS3 M 187, SYS 2 TL and so on. The model gives the box its size, which Stack Ctrl draws. It changes nothing else.

  1. Open the box and press Systainer model.
  2. Search by any name it goes by: M 187, SYS 2, T-Loc III, sort. The list covers TANOS and Festool boxes, grouped by generation and size, each with a small outline of its front. Older boxes are tagged Not sold now.
  3. Tap the one that matches and press Use this on that row.

Picking a Sortainer offers to add its drawers, already counted. Nothing is added until you say so.

Ships in. Most Festool tools come in a Systainer. When you tick one into its own new box, Tool Ctrl fills in the Systainer it ships in now and marks it Check your box, because a different set, or one bought before 2019, may have come in another. Press It's right once you've looked.

From the tools already in your boxes. In the Boxes view, Fill Systainer models from tools gives every Systainer without a model the one its Festool tool ships in, marked Check your box. It never changes a model you've set, and Undo puts it back. It knows the Systainer for the Festool tools listed so far; for the rest, pick the model yourself.

Many at once. Search the Boxes view, then Set Systainer model on these. Boxes that aren't Systainers, such as bags, are skipped.

Not listed. A box that isn't on the list can take a name and a height in mm instead. A spreadsheet with a systainer or size column fills models in on import.

Adding tools

Open a box or drawer and press Add tools. The tick-list has three kinds of tab.

  • My tools lists everything already in your record that isn't here, with where it is now. Tick one to move it here.
  • A maker's tab lists their tools, so you click what you own instead of typing it.
  • Hand tools is a plain list with no brand, for the screwdrivers, pliers and chisels that live in drawers. Add a brand on the tool if you like.

Choose where ticked tools go: into the box you have open, or Each into a new box. The second makes a box for every tick, with the next free number and the tool's name, which suits tools that live in their own case. Untick in the same visit and the new box goes away again.

Anything not on the list can be typed with Add a tool. Every field stays editable.

Consumables such as abrasives, blades and bits are hidden until you turn on Show consumables. They aren't counted as inventory, but a box of 125 mm abrasives can still list what it holds.

Read from photo

Open a box or drawer and press Read from photo. On an iPad it opens the camera; on a computer, choose a photo. Tool Ctrl reads the names it can see and suggests tools.

  • A match with the tool list comes ticked. A guess comes unticked.
  • A tool already in that box shows as Already here and isn't added twice.
  • Edit any name before you add it. The text it read is shown underneath.

Printed labels and model plates read best. Small or curved text, glare and low light read less reliably, so check every suggestion. The first photo loads the reader, about 14 MB. After that it works offline.

The photo is read on your device and let go when you add or cancel. It is never saved, synced or backed up.

From photos

With Photo Ctrl you photograph boxes, stacks and drawers, and your own Claude reads the photos and writes proposals to a proposals folder in your Tool Ctrl repo. When some are waiting, a From photos tab appears with the count, on a computer or iPad.

  • It shows one set at a time, with its photos when Photo Ctrl is connected in the same browser. Choose a change to see it outlined in the photo.
  • Changes Claude was sure of, or thought likely, come ticked. Guesses come unticked. A box is ticked when its label was read, even if its model was only guessed; the guessed model is left unset.
  • A new box takes the next free number. If its old label carries a free number with your prefix, such as WW-031, Keep the label's number is offered. Any other old number goes in its notes.
  • A tool already in the box shows as Already here. A tool recorded somewhere else shows where, and moves only if you tick it. A model different from the one recorded is kept unless you tick the change.
  • Add puts the ticked changes in, with Undo until your next change. Later keeps the set waiting. Decline marks it declined. Stacks wait for Stack Ctrl.

Photos are shown from your photo repo while you review and are never saved in Tool Ctrl, its backups or your Tool Ctrl repo.

Finding a tool

Find, under the header on every view, searches tools, boxes and drawers at once. On a computer, press / to put the cursor in it. On a phone it's the first thing on the screen.

Case, spaces, punctuation and word order don't matter: ets125, ETS 125 and 125 ets all find the ETS 125. A number on its own is read as a box number, so 14, ww14 and WW 14 all find WW-014 and put it first, with Open WW-014.

Results come in three groups, Boxes, Tools and Drawers, up to five each. Show all opens the rest. A box result shows where it is, its model, how many tools it holds and the first few. A box in a stack says where it sits, such as 2nd from the bottom on WW-068, with See in Stack Ctrl. Choose a tool and its box opens with the drawer chosen and the tool marked; ‹ Results takes you back to the search as you left it. Retired boxes and tools are left out unless you tick Include retired.

When Find is empty, it shows your last five searches. They're kept in this browser only and never synced; Clear recent searches removes them.

Each list also has its own filter. A result shows its full path, such as Shop wall › WW-067 › D3 › Trim router.

The Items view lists every tool, with filters and grouping. Select several to Move them, Set a field on all of them, or Retire them, and Undo if you change your mind. A moved tool keeps a line saying where it came from and when.

Warranty details

Any power or hand tool can carry its serial number, purchase date, seller, price, warranty length or end date, registration and a receipt link. All are optional.

  • The warranty end is worked out from the purchase date and length, unless you type an end date.
  • Warranty details belong to one tool. If a tool has a quantity above 1, Tool Ctrl offers to split one off.
  • A receipt is a link to wherever it already lives, such as a Drive file or an email. Tool Ctrl never fetches or stores it.
  • The Warranty view sorts tools by warranty end and shows which ones aren't registered. A tool's card has everything a claim needs, and Copy details puts it on the clipboard.

Importing a maker's warranty list

If you've registered your tools with the maker, you can bring them all in at once. In Record, press Import warranty list and choose the file. Tool Ctrl shows what it found before anything changes.

  • Each tool comes in as its own item, quantity 1, marked registered, with its serial number, purchase date, warranty end and warranty number. The part number goes in its notes.
  • Tools go to Loose. Open a box, then tick them in from My tools.
  • Names that match the built-in list take its name, kind and tier. Others keep the name from the file, so check those.
  • Importing the same list again adds only new tools, matched by serial number. It fills empty details on tools already here and never changes anything you typed.
  • Only those columns are read. Anything else in the file, such as your name or address, is ignored.

How to get your list from Festool. Sign in to your Festool account and open MyToolbox, which lists the tools you've registered. Export the list as a CSV file. It saves with a name like MyToolbox product overview.csv. Tool Ctrl reads the US export, with dates written month/day/year.

Importing a list

Record › Import a list reads a .csv with a name column. It also reads id, kind, location, contents (lines split by |), model and notes, and keeps any other columns with the box. A Box Ctrl spreadsheet export works. Save an Excel file as .csv first.

You see a summary before anything is added. IDs already used are listed and skipped, so importing twice doesn't double anything.

If the list uses another prefix, Tool Ctrl can renumber it to yours in the same order, keeping the number: ST-001 becomes WW-001. Where the old numbers have gaps, you can also number them in order, closing the gaps. That's off by default, because labels may already be printed. Each box keeps its old ID in its notes.

Labels with Box Ctrl

Tool Ctrl doesn't print. Box Ctrl does, with each box's number, name and what's in it. Because a box number never changes, a label stays right however often you move or restack the box.

With GitHub, the easy way. Connect Box Ctrl to the same private repo and token as Tool Ctrl; in the same browser it offers Use Tool Ctrl's repo. Then press Get boxes from Tool Ctrl. It shows what's new and what's changed before anything changes, and boxes you add later come across the same way.

Without GitHub, use a file. In Tool Ctrl, Record › Export for Box Ctrl saves a .csv, one row per box, and one per drawer if you choose. In Box Ctrl, open that file.

Either way, contents are built from tool names, two lines of up to 40 characters. If a box holds more than fits, Tool Ctrl names it and keeps the first tools that fit, without cutting a word. Only numbers, names, kinds and contents go across. Warranty details, locations and notes never do.

QR codes. Box Ctrl can print a QR code on each label that holds only a link to that box here. Scan it with a phone camera and Tool Ctrl opens on that box. If the phone has no record yet, Tool Ctrl says which box was asked for, and opens it once the record is there.

Stacks with Stack Ctrl

Stack Ctrl draws every Systainer in your record from the front, to scale, and lets you drag them into stacks on the floor or on a cart. Each stack shows how tall it stands, in mm and inches.

  1. Give your Systainers their models here (see Systainer models). A box without one shows as an outline at a standard height.
  2. Open Stack Ctrl in the same browser. It reads this record directly; there's nothing to export.
  3. Drag a box from the tray onto the floor to start a stack, then drop boxes on top, between two, or onto a cart. It won't stack boxes that don't latch, such as a Classic on a newer box, and says why.

Stack Ctrl changes only where each box sits. Tool Ctrl shows the result as Sits on and location, and syncs it to GitHub like any other change, so the stacks reach your other devices. Names, models and contents are changed here, in Tool Ctrl.

Arrange stacks on a computer or iPad. On a phone, Stack Ctrl is for looking.

On a phone

A screen under 768 px wide is review only. Open boxes, search, read the Items and Warranty views and copy a warranty card. Adding, moving, photos, import and export are left off, so nothing changes by accident.

The record reaches a phone from GitHub, or from a backup file. A phone only reads from GitHub and never writes to it, so a token with read-only rights is enough there.

Keeping your record

Without GitHub, your record lives only in this browser on this device. Clearing browser data removes it. So keep a copy.

  • Export backup saves tool-ctrl-YYYY-MM-DD.json with everything. Open a backup replaces the record, after you confirm.
  • Export items saves a spreadsheet of every tool, with where it is and its warranty details.

Storing it on GitHub

This is optional. A GitHub repo of your own holds the record as a file, syncs it between devices and keeps a history of every change. You need a free GitHub account.

New to GitHub? Follow Set up GitHub, step by step, in the WOODWERD Toolkit Guides. One private repo and one token serve every WOODWERD tool that syncs. The short version is below.

1. Make a private repo

  1. On GitHub, choose New repository. Name it something like ctrl-data.
  2. Set it to Private. Your record can hold serial numbers and where your tools are kept, so keep it out of public view.
  3. Create it. It can be empty; Tool Ctrl adds its own files. If another WOODWERD tool already uses a repo, use that one.

2. Make a token for that repo only

  1. In GitHub, open Settings › Developer settings › Personal access tokens › Fine-grained tokens, and choose Generate new token. The Make a token on GitHub button in Tool Ctrl goes straight there.
  2. Give it a name and an expiry date.
  3. Under Repository access, choose Only select repositories, and pick your data repo.
  4. Under Repository permissions, set Contents to Read and write. Leave everything else as it is. For a phone, make a second token with Contents set to Read-only.
  5. Generate it and copy it. GitHub shows it once.

3. Connect

  1. In Tool Ctrl, open Record › Connect to GitHub.
  2. Type the repo as owner/name, such as yourname/ctrl-data, paste the token and press Connect.
  3. An empty repo gets tool-ctrl.json and a README. A repo that already holds a record asks whether to use the repo's record or this device's, and says how many boxes each has.

Connect each device on its own. The token stays on that device, and never goes in a link, an export, a backup or the repo. Disconnect deletes it.

How syncing works. Changes save on the device at once and go to GitHub a few seconds after your last edit, when the app opens, and on Sync now. Each sync is one commit you can see on GitHub. Offline, changes wait and go up when you're back. If two devices change the same field, Tool Ctrl shows both values and asks which to keep. If two add the same new box number, the second to sync takes the next free number and says so.

When a token expires, make a new one the same way and paste it in. Tool Ctrl carries on where it left off.

Errors and fixes

That file has no Name column: add a name column, or start from a Box Ctrl export.

WW-014 is already used: that box is in your record. It's skipped, and nothing doubles.

GitHub refused the token: it is wrong, expired or missing rights. Make a new one with Contents read and write for that repo. Your changes stay on the device until then.

This token can read the repo but not write to it: give it Contents read and write.

Storage is running low: export a backup, then connect GitHub so you have a second copy.

Privacy

Tool Ctrl has no server and no analytics. Your record stays on this device. The only network requests it makes after loading go to api.github.com, for your own data repo, and only after you connect. Photos are read on the device and never kept.
