# Tool Ctrl

Every tool box you own, and what's in it.

Tool Ctrl gives each box a permanent number, such as WW-014, and each drawer its own, such as WW-014-D2. You tick off the tools in each from a list of the brands you own, or type them. Search finds any tool and says exactly where it is. A Warranty view keeps serial numbers and purchase dates ready for a claim. When you want labels, Tool Ctrl exports in the format [Box Ctrl](https://woodwerd.github.io/box-ctrl/) imports.

- Runs in your browser and works offline. Your record stays on your device.
- Build and change the record on a computer or iPad. A phone is for looking things up.
- Export a backup to keep a copy or move it to another device.
