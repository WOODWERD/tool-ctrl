# Changelog

What changed in each version of [Tool Ctrl](https://woodwerd.github.io/tool-ctrl/), newest first. Versions are x-numbers while Tool Ctrl is a public beta.

## x0.0.9 · 2026-11-03
- Find, under the header on every view: one search for tools, boxes and drawers. On a computer, press / to jump to it.
- Case, spaces, punctuation and word order don't matter, so "ets125" finds the ETS 125. A number alone is read as a box number: "14", "ww14" and "WW 14" all open WW-014.
- Results come in Boxes, Tools and Drawers. A box in a stack says where it sits, with See in Stack Ctrl.
- Choosing a tool opens its box with the drawer chosen and the tool marked. Back returns to your results as you left them.
- Your last five searches show when Find is empty. They stay in that browser and are never synced.
- Box links: woodwerd.github.io/tool-ctrl/#WW-014 opens that box. Box Ctrl's QR codes use this, so scanning a label opens its box.
- The Items search and the box list filter now ignore spaces and punctuation too.

## x0.0.8 · 2026-11-02
- Live updates with Stack Ctrl: a box moved there shows here within a second.
- The Systainer model picker shows the whole list grouped by box type, with a Use this button on each row.
- Fill Systainer models from tools sets each box's model from the tools in it, marked to check.
- The user guide covers Systainer models, labels with Box Ctrl and stacks with Stack Ctrl.

## x0.0.7 · 2026-11-02
- Systainer models. A box can carry its exact model, picked by any name, from 76 TANOS and Festool models with their sizes. Stack Ctrl draws boxes from this.
- A tool ticked into a new box gives the box the Systainer it ships in, marked to check.

## x0.0.6 · 2026-11-02
- The guide's GitHub section and the Connect form link to the Set up GitHub page.

## x0.0.5 · 2026-11-02
- Import a maker's warranty list, starting with Festool MyToolbox: one tool per registered serial, with purchase date, warranty end and warranty number. A second import adds only what's new. Undo reverses it.

## x0.0.4 · 2026-11-02
- The user guide.
- 75 Festool tools added to the catalog.
- Public beta at woodwerd.github.io/tool-ctrl.

## x0.0.3 · 2026-11-02
- Read from photo: photograph a drawer and Tool Ctrl suggests the tools it reads. The photo is read on the device and never kept, synced or backed up.

## x0.0.2 · 2026-11-02
- Optional GitHub storage in your own private repo, with sync between devices and a choice when the same thing changed in two places.
- Tick-list: My tools moves tools you've already recorded into a box, and ticked tools can each go into a new box.

## x0.0.1 · 2026-11-02
- Every tool box, its drawers and the tools in them, each box with a permanent number.
- Tick-list by maker, Items with search, filters and bulk move with Undo, and a warranty list with a card for claims.
- Import with renumbering, export for Box Ctrl labels, and backups.
- On a phone, Tool Ctrl is for looking things up; changes happen on a computer or iPad.
